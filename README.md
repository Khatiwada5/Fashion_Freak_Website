# Fashion Freak Website

## About

Fashion Freak is a responsive multi-page fashion e-commerce website built with HTML, CSS, Bootstrap, and JavaScript. It showcases men, women, children, wedding, gallery, gift card, order tracking, and contact pages in a clean retail storefront experience.

**Live Demo:** [khatiwada5.github.io/Fashion_Freak_Website](https://khatiwada5.github.io/Fashion_Freak_Website/)

**Repository:** [Khatiwada5/Fashion_Freak_Website](https://github.com/Khatiwada5/Fashion_Freak_Website)

## Project Overview

This project was built as a front-end e-commerce website prototype for a fashion retail brand. It focuses on responsive layouts, product-category browsing, visual merchandising, and simple customer-facing pages that resemble a real online clothing store.

## Features

- Responsive home page with image slider and branded fashion layout
- Product-category pages for men's, women's, children's, and wedding collections
- Gallery page for visual product browsing
- Contact page for customer communication
- Gift card and order tracking pages
- Bootstrap-based responsive design
- Custom CSS/SCSS styling
- JavaScript interactions for a more dynamic storefront feel

## Technologies Used

- HTML
- CSS
- SCSS
- Bootstrap
- JavaScript
